# Recruiter Portfolio

A recruiter-focused personal portfolio built with Next.js and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Replace before publishing

Edit `app/page.tsx` and replace:

- `hello@example.com`
- `#` GitHub / LinkedIn / project links
- `/resume.pdf` after adding your resume to `public/resume.pdf`
- Any project descriptions as your projects evolve

## Recommended deployment

Vercel is the simplest option for this Next.js project.

## Design direction

- Technical/editorial rather than flashy
- Large typography and strong whitespace
- Minimal accent color
- Projects carry most of the proof
- No self-rated skill bars
